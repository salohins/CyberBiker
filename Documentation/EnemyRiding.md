Enemy routing uses the existing AIController dodge-point algorithm: forward-only candidates, the configured dodge angle, the original capsule obstacle test, and random choice among reachable car-generated points. The extra controller no longer replaces the root heading or lateral velocity, and there is no predictive braking layer. Mesh yaw/bank remain visual and use actual movement.

Each director-managed rider also has one reusable, private road waypoint, 25–65 units ahead, aimed toward its assigned lane. This fills the empty stretches between car rows without growing the shared navigation list. Its angle is limited to the configured dodge angle and it must pass the same capsule test as every original car-generated point. Reachable car-generated points within the local waypoint horizon (plus 10 units) take priority. An inserted road point must also have a capsule-clear onward connection to the original car-point network within the configured turn angle. If there is traffic ahead but no reachable network point, a short road point cannot disguise the dead end. Spawn positions use the same connectivity test. This preserves the relationship between traffic spacing, dodge points and the configured turn limit. Once a rider has passed traffic, nearby road waypoints spread the group back toward their assigned lanes instead of drawing everyone toward the next distant car.

The director assigns less occupied lanes and periodically swaps adjacent preferences. Changing a preference does not clear an active traffic detour. The rider finishes its selected path first. Enemy riding style on each difficulty controls lane preference timing, weave, visual drift yaw and bank. Slide Lean Reference Speed controls how much actual sideways speed produces full visual lean; it does not limit navigation speed. The former separate lateral-acceleration setting was removed with the competing movement controller.

The global GameplayManager following distance and the normal/Launch catch-up speed controller remain authoritative. Only the final swept navigation sphere limits a step that would actually overlap a car. Its radius is the original AIController collision radius, shared with the capsule route test. If moving traffic invalidates a route, that limit causes the enemy to ask the original planner for a new route. It does not apply speculative slowdown to a route that is already clear. The earlier rectangular mesh-envelope clamp was removed because it rejected routes the original planner accepted. The navigation sphere uses the root position and the same clearance as the planner; it does not redefine the bike's collision size independently. Destroyed cars with disabled colliders do not block navigation.

Both enemy prefabs use larger player-style Cartoon FX wheel smoke clouds and brighter skid sparks, with measured tire contact anchors, gentler lean activation, pause behavior and range culling. See EnemyWheelEffects.md for their current visual tuning. Reduced red trail brightness/width and finisher suppression are unchanged.
